KNOTOS INSTALLATION GUIDE PLATFORMIO / ARDUINO

1. CLONE REPOSITORY & SUBMODULES

Make sure to recursive clone to pull the KryptKernel submodule properly:

git clone --recursive https://github.com/DlopedDtorred/KnotOS.git

2. COMPILE & FLASH WITH PLATFORMIO

Connect your ESP32 board via USB-C/MicroUSB and run the build and upload target:

# Build project binaries

pio run


# Flash firmware onto ESP32

pio run --target upload


# Flash LittleFS filesystem image

pio run --target uploadfs

3. ACCESS KNOTOS TERMINAL

Open serial communication monitor at 115200 baud to start using KnotShell:

pio device monitor -b 115200
