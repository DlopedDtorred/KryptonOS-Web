KryptonOS Core Features & Command Shell

Integrated utilities available within the built-in KryptShell environment.

1. Built-in UNIX Commands

Manage LittleFS flash memory, navigate directories, and manipulate system files using standard syntax.

ls [-l] - List files and directories in current path

cd [path] - Change working directory

cat [file] - Print file content to terminal output

rm [file] - Remove entry from LittleFS filesystem

mkdir [dir] - Create a new directory

2. System Utilities & Diagnostics

Monitor ESP32 system state, heap usage, CPU frequency, and task manager routines in real-time.

free - Display current RAM allocations and available Heap

top - Real-time FreeRTOS task manager status

neofetch - Display system logo and hardware specs banner

reboot - Hard reset system MCU via software restart

3. Networking Stack (KryptNet Utility)

Configure WiFi interfaces and run basic network tests directly from the command line.

wifi connect [SSID] [PASS] - Join wireless network

ifconfig - Print assigned IP, gateway, and MAC address

curl [URL] - Fetch HTTP resource over the network
