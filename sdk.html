KNOTOS-SDK(7)

Create apps for KnotOS

The SDK compiles your application into the KnotOS ESP32 firmware. Apps run as managed FreeRTOS tasks; they are not dynamic plugins.

Create and build

cd KnotOS
python3 tools/knot_app.py ../MyKnotApp
pio run -d ../MyKnotApp

The generator links KnotOS and KryptKernel. If the repositories are not adjacent, use --knot-root and --kryptkernel-root.

Register an app

#include <KnotApp.h>

KnotOS::System os;

void appSetup() { pinMode(2, OUTPUT); }
void appLoop() { digitalWrite(2, !digitalRead(2)); }

void setup() {
  Serial.begin(115200);
  os.registerApp(KNOT_APP("blink", appSetup, appLoop));
  os.boot();
}

void loop() { os.run(); }

Apps are registered before boot(). Up to eight unique apps are supported.

Flash and launch

pio run -d ../MyKnotApp -t upload
pio device monitor -b 115200

In KnotOS Shell:

apps
apps blink

apps lists applications and states. apps blink starts the stopped app and executes its setup once, then its loop in a kernel-managed task.
