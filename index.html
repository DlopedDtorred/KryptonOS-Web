Welcome to KryptonOS Linux-like Embedded Distribution

KryptonOS Distribution

An open-source Linux-inspired operating system environment built for ESP32 microcontrollers. Features interactive command-line shell, LittleFS user space, system utilities, and full KryptKernel integration.

$ ./flash_firmware.sh $ man kryptonos

🖥️ KryptShell CLI

Interactive terminal interface supporting UNIX standard commands like ls, cd, cat, free, and reboot via Serial/UART.

⚙️ Powered by KryptKernel

Uses KryptKernel as a low-level Git submodule for hardware abstraction, multitasking, memory, and filesystem management.

📦 User Space Apps

Built-in system packages, network tools, system monitors, and scripts execution right out of the box.
